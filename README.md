# Protocolo REI-JAL

Sistema web para la captura, estandarización y generación de protocolos de investigación en saludo del Registro Estatal de Investigación de Jalisco (REI-JAL)

La plataforma permite capturar la información principal de un protocolo de investigación así como generar un documento PDF estandarizado para su entrega institucional.
Además, contiene el seguimiento a un formulario de Google para subir los archivos necesarios.
